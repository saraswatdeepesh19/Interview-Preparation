# What are the key ES6 plus features

---

## 🟢 Junior Level

**ES6 (ES2015)** was the biggest upgrade in JavaScript history, and the language has received a yearly release since (ES2016 ... ES2023, ES2024). "ES6+" refers to this modern syntax that every project today uses. Key features: `let/const`, arrow functions, template literals, destructuring, spread/rest, modules, classes, `Promise`, and later `async/await`.

### Simple Real-World Analogy
Old JavaScript was a hand-cranked car: it worked, but needed a lot of manual effort. ES6+ is the same car with power steering, GPS and automatic gearbox: same engine (the language runtime), much less boilerplate.

### Minimal examples

```js
// Arrow functions + template literals
const greet = (name) => `Hello, ${name}!`;

// Destructuring
const user = { id: 1, name: 'Ann', address: { city: 'Berlin' } };
const { name, address: { city } } = user;
const [first, , third = 'default'] = ['a', 'b'];

// Default and rest parameters
function sum(base = 0, ...nums) { return nums.reduce((a, b) => a + b, base); }

// Spread
const merged = { ...user, name: 'Bob' };      // copy + override
const all = [...[1, 2], ...[3, 4]];
Math.max(...all);

// Shorthand and computed properties
const key = 'role';
const obj = { name, [key]: 'admin', hello() { return 'hi'; } };
```

### Modules

```js
// math.js
export const PI = 3.14159;
export function add(a, b) { return a + b; }
export default class Calculator {}

// app.js
import Calculator, { PI, add } from './math.js';
```

```html
<script type="module" src="app.js"></script>
```

### async/await in one minute

```js
async function loadUser(id) {
  const res = await fetch(`/api/users/${id}`);
  if (!res.ok) throw new Error('HTTP ' + res.status);
  return res.json();
}
```

## 🟡 Middle Level

### Feature map by year

| Version | Highlights |
|---|---|
| ES2015 | let/const, arrow, classes, modules, template literals, destructuring, Promise, Map/Set, Symbol, generators, iterators |
| ES2016-17 | `**`, `Array.includes`, `Object.entries/values`, `async/await`, `padStart` |
| ES2018 | object rest/spread, `Promise.finally`, async iterators, regex named groups |
| ES2019 | `flat/flatMap`, `Object.fromEntries`, optional catch binding |
| ES2020 | `?.`, `??`, `BigInt`, `Promise.allSettled`, `import()`, `globalThis` |
| ES2021 | `??=`, `||=`, `&&=`, `replaceAll`, `Promise.any`, numeric separators |
| ES2022 | top-level `await`, `#private`, class fields, `Array.at`, `Object.hasOwn`, `Error.cause` |
| ES2023 | `toSorted`, `toReversed`, `toSpliced`, `with`, `findLast`, hashbang |
| ES2024 | `Object.groupBy`, `Map.groupBy`, `Promise.withResolvers`, `Array.fromAsync` |

### Optional chaining and nullish coalescing

```js
const city = user?.address?.city ?? 'Unknown';   // ?? only for null/undefined
const port = config.port || 3000;                // || also replaces 0 and '' - often a bug
const port2 = config.port ?? 3000;               // correct for 0
cache.value ??= computeExpensive();
```

### Array and object toolkit

```js
const orders = [{ id: 1, total: 50, status: 'NEW' }, { id: 2, total: 120, status: 'PAID' }];

const paid = orders.filter(o => o.status === 'PAID').map(o => o.total);
const sum = orders.reduce((acc, o) => acc + o.total, 0);

const byStatus = Object.groupBy(orders, o => o.status);   // ES2024
const sorted = orders.toSorted((a, b) => b.total - a.total); // non-mutating (ES2023)
const entries = Object.fromEntries(Object.entries({ a: 1, b: 2 }).map(([k, v]) => [k, v * 2]));
```

### Map, Set, WeakMap

```js
const unique = [...new Set([1, 2, 2, 3])];
const m = new Map([['a', 1]]);  m.set({ x: 1 }, 'obj-key');  // any key type, insertion order
const cache = new WeakMap();    // keys are objects, don't prevent GC
```

### ES modules vs CommonJS

| | ESM | CommonJS |
|---|---|---|
| Syntax | `import/export` | `require/module.exports` |
| Loading | static, async, tree-shakeable | dynamic, synchronous |
| Live bindings | yes | copies of values |
| `this` at top | `undefined` | `module.exports` |
| Top-level await | yes | no |

```js
// Dynamic import for code splitting
button.addEventListener('click', async () => {
  const { openChart } = await import('./chart.js');
  openChart();
});
```

### Common mistakes
- Spread only copies **shallowly**; nested objects stay shared. Use `structuredClone` for deep copies.
- Mutating arrays inside React state (`push`) instead of creating new ones.
- Using `for...in` on arrays.
- Destructuring `null` throws a TypeError; provide defaults `= {}`.
- Forgetting `.js` extensions in native browser/Node ESM imports.

## 🔴 Senior Level

### Iterators, generators and async iteration
Any object with `[Symbol.iterator]()` works with `for...of`, spread and destructuring. Generators make lazy sequences trivial; async generators model streams (paginated APIs, SSE).

```js
function* range(start, end, step = 1) {
  for (let i = start; i < end; i += step) yield i;
}
console.log([...range(0, 10, 3)]); // [0, 3, 6, 9]

async function* pages(url) {
  let next = url;
  while (next) {
    const res = await fetch(next);
    const body = await res.json();
    yield* body.items;
    next = body.nextPage;           // follow the pagination
  }
}
for await (const item of pages('/api/orders?page=0')) console.log(item.id);
```

### Proxy and Reflect (basis of Vue 3 reactivity)

```js
const reactive = (target, onChange) => new Proxy(target, {
  set(obj, prop, value, receiver) {
    const ok = Reflect.set(obj, prop, value, receiver);
    onChange(prop, value);
    return ok;
  }
});
const state = reactive({ count: 0 }, (k, v) => console.log(k, v));
state.count++;
```

### Build targets, transpilation and polyfills
Browsers differ; tools (Babel, SWC, esbuild, TypeScript) downlevel syntax according to a `browserslist` or `target`. Syntax can be transpiled; **APIs need polyfills** (core-js). Over-broad targets (IE11) inflate bundles; modern apps serve `type="module"` for evergreen browsers. Use [Vite/Webpack](13.%20What%20are%20npm%20Vite%20and%20Webpack.md) config to pick `es2022` targets.

### Pitfalls with precision and types
- `BigInt` for values beyond 2^53-1 (Java `long` IDs!). JSON.parse turns a 64-bit ID into an imprecise Number — a classic Java/JS integration bug.

```js
JSON.parse('{"id": 9007199254740993}').id;   // 9007199254740992 (lost precision)
```
Fix: serialize IDs as strings (`@JsonSerialize(using = ToStringSerializer.class)` in Jackson) or use `JSON.parse` reviver with source text access where supported.

- `Date` is notoriously poor; use ISO-8601 strings and libraries (date-fns, Luxon) until the Temporal API ships broadly.
- `Intl` APIs (`NumberFormat`, `DateTimeFormat`, `PluralRules`) provide localization without libraries.

### Performance considerations
- `reduce` with spread (`{...acc, [k]: v}`) is O(n^2); mutate a local accumulator.
- Prefer `Map` for frequent add/delete; `Set` for membership instead of `includes` on large arrays.
- Tree-shaking requires static ESM and side-effect-free modules (`"sideEffects": false` in package.json).
- Top-level `await` blocks module graph evaluation: avoid in widely imported modules.

## 🎯 Interview Cheat Sheet

**30-second pitch:** ES6+ gave JavaScript block scoping, arrows, destructuring, spread, modules, classes, promises and async/await; later years added `?.`, `??`, private fields, top-level await, immutable array methods and grouping. Know shallow-vs-deep copy, ESM vs CJS, and how transpilers/polyfills ship them to browsers.

**Must-know bullets**
- Destructuring, spread/rest, template literals.
- `?.` and `??` vs `||`.
- ESM static imports, dynamic `import()`, tree shaking.
- `Map`/`Set`/`WeakMap`; iterators & generators.
- 64-bit integers lose precision in JSON numbers.

**Common follow-up questions**
1. Difference between arrow and regular function?
2. Shallow vs deep copy and `structuredClone`?
3. What is tree shaking and why does ESM enable it?
4. `Promise.all` vs `allSettled` vs `any` vs `race`?

**Red flags**
- Mutating state arrays/objects in React.
- Using `||` for defaults on numeric/boolean values.
- Not knowing a transpiler cannot add missing runtime APIs.
