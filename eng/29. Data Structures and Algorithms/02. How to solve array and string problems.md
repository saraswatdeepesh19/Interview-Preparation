# How to solve array and string problems

---

## 🟢 Junior Level

An **array** is a fixed-size, contiguous block of memory holding elements of one type; access by index is `O(1)`. A Java `String` is an **immutable** sequence of characters backed internally by a `byte[]` (Latin-1 or UTF-16, since Java 9). Most beginner interview tasks are "walk through the data once and keep a little state".

### Real-world analogy
An array is a row of numbered lockers: jumping to locker #57 is instant, but inserting a new locker in the middle forces everyone after it to shift.

### Typical tasks
- Find max/min, reverse, rotate, remove duplicates in a sorted array
- Check palindrome, count vowels, reverse words

```java
import java.util.Arrays;

public class ArrayStringBasics {

    // O(n) time, O(1) space: in-place reverse
    static void reverse(int[] a) {
        for (int i = 0, j = a.length - 1; i < j; i++, j--) {
            int tmp = a[i];
            a[i] = a[j];
            a[j] = tmp;
        }
    }

    // Palindrome ignoring non-alphanumerics and case: O(n) time, O(1) space
    static boolean isPalindrome(String s) {
        int i = 0, j = s.length() - 1;
        while (i < j) {
            while (i < j && !Character.isLetterOrDigit(s.charAt(i))) i++;
            while (i < j && !Character.isLetterOrDigit(s.charAt(j))) j--;
            if (Character.toLowerCase(s.charAt(i)) != Character.toLowerCase(s.charAt(j))) {
                return false;
            }
            i++;
            j--;
        }
        return true;
    }

    // Maximum element, assumes non-empty array
    static int max(int[] a) {
        int best = a[0];
        for (int x : a) best = Math.max(best, x);
        return best;
    }

    public static void main(String[] args) {
        int[] a = {1, 2, 3, 4, 5};
        reverse(a);
        System.out.println(Arrays.toString(a));                       // [5, 4, 3, 2, 1]
        System.out.println(isPalindrome("A man, a plan, a canal: Panama")); // true
        System.out.println(max(a));                                    // 5
    }
}
```

### Always check edge cases
Empty array, single element, all equal, negative numbers, `null`, very large values (integer overflow), Unicode characters.

## 🟡 Middle Level

### Pattern toolbox
| Pattern | Use when | Typical complexity |
|---|---|---|
| Single pass + running state | max subarray, running sum | O(n) / O(1) |
| Prefix sums | many range-sum queries | O(n) build, O(1) query |
| In-place swap / partition | remove, move zeroes, Dutch flag | O(n) / O(1) |
| Sorting first | duplicates, closest pairs, merging | O(n log n) |
| Hash map / set | membership, counting | O(n) / O(n) |
| Two pointers / sliding window | sorted or contiguous problems (see the dedicated question) | O(n) |

### Kadane's algorithm — maximum subarray
Brute force tries all `O(n²)` subarrays. Kadane keeps the best subarray *ending here*: either extend the previous one or start fresh.

```java
public class Kadane {
    static int maxSubArray(int[] nums) {
        int cur = nums[0], best = nums[0];
        for (int i = 1; i < nums.length; i++) {
            cur = Math.max(nums[i], cur + nums[i]);
            best = Math.max(best, cur);
        }
        return best;
    }

    public static void main(String[] args) {
        System.out.println(maxSubArray(new int[]{-2, 1, -3, 4, -1, 2, 1, -5, 4})); // 6
    }
}
```

### Prefix sums and product-except-self

```java
import java.util.Arrays;

public class PrefixTricks {

    // Range sum queries in O(1) after O(n) preprocessing
    static long[] buildPrefix(int[] a) {
        long[] p = new long[a.length + 1];
        for (int i = 0; i < a.length; i++) p[i + 1] = p[i] + a[i];
        return p;
    }

    static long rangeSum(long[] p, int l, int r) { // inclusive l..r
        return p[r + 1] - p[l];
    }

    // Product of array except self without division: O(n) time, O(1) extra space
    static int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] res = new int[n];
        res[0] = 1;
        for (int i = 1; i < n; i++) res[i] = res[i - 1] * nums[i - 1];
        int right = 1;
        for (int i = n - 1; i >= 0; i--) {
            res[i] *= right;
            right *= nums[i];
        }
        return res;
    }

    public static void main(String[] args) {
        long[] p = buildPrefix(new int[]{3, 1, 4, 1, 5});
        System.out.println(rangeSum(p, 1, 3));                       // 6
        System.out.println(Arrays.toString(productExceptSelf(new int[]{1, 2, 3, 4}))); // [24, 12, 8, 6]
    }
}
```

### Rotate array and move zeroes
Rotating by `k` in `O(n)` time / `O(1)` space: reverse the whole array, then reverse the first `k` and the last `n-k` elements. Remember `k %= n`.

```java
public class RotateMove {
    static void rotate(int[] a, int k) {
        int n = a.length;
        k %= n;
        reverse(a, 0, n - 1);
        reverse(a, 0, k - 1);
        reverse(a, k, n - 1);
    }

    private static void reverse(int[] a, int l, int r) {
        while (l < r) {
            int t = a[l]; a[l++] = a[r]; a[r--] = t;
        }
    }

    // Stable: keeps relative order of non-zero values
    static void moveZeroes(int[] a) {
        int w = 0;
        for (int x : a) if (x != 0) a[w++] = x;
        while (w < a.length) a[w++] = 0;
    }
}
```

### String-specific pitfalls
- `String` is immutable: `s += c` in a loop is `O(n²)`; use `StringBuilder`.
- Compare with `equals`, never `==`.
- `charAt` iterates UTF-16 code units, **not** Unicode code points; emoji are surrogate pairs. Use `s.codePoints()` when correctness for non-BMP characters matters.
- `s.toCharArray()` costs `O(n)` memory, but gives you a mutable buffer.
- `String.split` uses a regex — slow in hot paths; prefer `indexOf` loops.

### Frequency counting
For lowercase-only input use `int[26]` instead of a `HashMap<Character,Integer>`: no boxing, no hashing, cache friendly.

## 🔴 Senior Level

### Memory and performance realities
- `int[]` of 1M elements = ~4 MB contiguous; `Integer[]`/`List<Integer>` = 16-byte objects plus references, ~5× larger and cache-unfriendly. Prefer primitive arrays in hot paths (or `IntStream`, fastutil, Eclipse Collections).
- Arrays are covariant and checked at runtime: `Object[] o = new String[1]; o[0] = 1;` throws `ArrayStoreException`. Generic arrays cannot be created directly.
- `System.arraycopy` / `Arrays.copyOf` are JVM intrinsics using vectorised memory moves — always faster than hand-written loops for bulk copy.
- Bounds-check elimination: the JIT removes checks in simple counted loops (`for (int i = 0; i < a.length; i++)`); tangled index arithmetic may defeat it.
- Auto-vectorisation (SIMD) of simple loops such as sum/min/max on `int[]` happens in C2; branches and method calls inside the loop usually block it. The Vector API (incubator) exposes it explicitly.

### Overflow and correctness
```java
public class OverflowSafe {
    // Prefix sums over int arrays can overflow int: use long
    static long sum(int[] a) {
        long s = 0;
        for (int x : a) s += x;
        return s;
    }

    // Classic bug: (lo + hi) / 2 can overflow
    static int mid(int lo, int hi) {
        return lo + (hi - lo) / 2;      // or (lo + hi) >>> 1
    }

    // Math.abs(Integer.MIN_VALUE) is still negative; use Math.absExact or long
    static int safeAbs(int x) {
        return Math.absExact(x);        // throws ArithmeticException for MIN_VALUE
    }
}
```

### Large-scale strings
- **Compact Strings** (JDK 9+): a Latin-1-only string uses 1 byte per char; one non-Latin-1 character promotes the whole string to UTF-16 (2 bytes).
- **String interning/deduplication**: G1's `-XX:+UseStringDeduplication` shrinks heaps with many duplicate strings (e.g., parsed JSON keys).
- **substring** copies since JDK 7u6 — it no longer leaks the parent's char array, but is `O(k)`.
- For streaming data that does not fit in memory, process in chunks with `BufferedReader`, and never accumulate unbounded `StringBuilder`s.
- Parsing in hot paths: `Integer.parseInt(CharSequence, begin, end, radix)` (JDK 9+) avoids creating substrings.

### In-place algorithm: Dutch national flag (sort colors 0/1/2)

```java
public class DutchFlag {
    // Single pass, O(n) time, O(1) space, three-way partition
    static void sortColors(int[] a) {
        int low = 0, mid = 0, high = a.length - 1;
        while (mid <= high) {
            switch (a[mid]) {
                case 0 -> swap(a, low++, mid++);
                case 1 -> mid++;
                default -> swap(a, mid, high--);   // do not advance mid: swapped value is unchecked
            }
        }
    }

    private static void swap(int[] a, int i, int j) {
        int t = a[i]; a[i] = a[j]; a[j] = t;
    }
}
```

### Production considerations
- Defensive copies: never expose internal arrays (`return data.clone()` or `List.copyOf`).
- Thread safety: arrays have no visibility guarantees per element; use `AtomicIntegerArray` or `VarHandle` for concurrent counters, or `LongAdder` striping.
- Cache-friendly layout: a 2D `int[n][m]` is an array of arrays; flattening to `int[n*m]` improves locality (see the matrix question).
- Diagnostics: `ArrayIndexOutOfBoundsException` and `NegativeArraySizeException` are usually off-by-one or overflow bugs; add property-based tests (jqwik) with random sizes including 0, 1, `Integer.MAX_VALUE` boundary arithmetic.

## 🎯 Interview Cheat Sheet

### 30-Second Elevator Pitch
> "For array and string problems I first clarify constraints and edge cases, then pick a pattern: single pass with state (Kadane), prefix sums for range queries, in-place swapping for O(1) space, a hash map for counting, or two pointers. I use `StringBuilder` for building strings, primitive arrays for performance, and guard against overflow and Unicode surprises."

### Must-Know Bullets
- Array access O(1); insert/delete in the middle O(n).
- Strings are immutable — concatenation in a loop is O(n²).
- Kadane = max subarray in O(n); prefix sums = O(1) range queries.
- Reverse-three-times trick rotates an array in O(1) space.
- Use `lo + (hi - lo) / 2` to avoid overflow.

### Common Follow-Up Questions
1. How to do it in O(1) extra space? In one pass?
2. What if the input is sorted? What if it does not fit in memory?
3. How do you handle Unicode and surrogate pairs?
4. Why is `String` immutable and how does that affect concurrency and hashing?

### Red Flags (DO NOT Say)
- ❌ "I'll just concatenate with `+` in the loop."
- ❌ Ignoring empty/null input and negative numbers.
- ❌ Using `==` for string comparison.
- ❌ Boxing `int` into `Integer` lists without a reason in performance-sensitive code.
