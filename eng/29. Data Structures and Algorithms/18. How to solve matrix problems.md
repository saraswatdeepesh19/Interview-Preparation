# How to solve matrix problems

---

## 🟢 Junior Level

A **matrix** (2D grid) is an array of rows: `int[][] m` with `m.length` rows and `m[0].length` columns. Matrix problems test careful indexing more than clever algorithms. Common building blocks:

```java
int rows = m.length, cols = m[0].length;

// Four-directional neighbors without copy-paste
static final int[][] DIRS = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

boolean inBounds(int r, int c, int rows, int cols) {
    return r >= 0 && r < rows && c >= 0 && c < cols;
}

for (int[] d : DIRS) {
    int nr = r + d[0], nc = c + d[1];
    if (inBounds(nr, nc, rows, cols)) { /* visit m[nr][nc] */ }
}
```

### Traversal orders
* Row-major (`for r ... for c ...`) is cache-friendly in Java because each row is a contiguous array.
* Column-major on large matrices is several times slower due to cache misses — worth mentioning for performance questions.

### Transpose and rotate 90° clockwise in place

```java
void rotate(int[][] m) {                     // n x n
    int n = m.length;
    for (int i = 0; i < n; i++)              // 1. transpose
        for (int j = i + 1; j < n; j++) { int t = m[i][j]; m[i][j] = m[j][i]; m[j][i] = t; }
    for (int[] row : m)                      // 2. reverse each row
        for (int l = 0, r = n - 1; l < r; l++, r--) { int t = row[l]; row[l] = row[r]; row[r] = t; }
}
```

## 🟡 Middle Level

### Spiral order

```java
List<Integer> spiral(int[][] m) {
    List<Integer> out = new ArrayList<>();
    int top = 0, bottom = m.length - 1, left = 0, right = m[0].length - 1;
    while (top <= bottom && left <= right) {
        for (int c = left; c <= right; c++) out.add(m[top][c]);
        top++;
        for (int r = top; r <= bottom; r++) out.add(m[r][right]);
        right--;
        if (top <= bottom) { for (int c = right; c >= left; c--) out.add(m[bottom][c]); bottom--; }
        if (left <= right) { for (int r = bottom; r >= top; r--) out.add(m[r][left]); left++; }
    }
    return out;
}
```

The two `if` guards handle single remaining rows/columns — the classic off-by-one trap.

### Search in a sorted matrix
If rows and columns are both sorted ascending, start at the **top-right** corner: move left if the value is too big, down if too small — O(rows + cols):

```java
boolean search(int[][] m, int target) {
    int r = 0, c = m[0].length - 1;
    while (r < m.length && c >= 0) {
        if (m[r][c] == target) return true;
        if (m[r][c] > target) c--; else r++;
    }
    return false;
}
```

If the matrix is fully sorted row after row, treat it as a 1D array of length `rows * cols` and binary search with `m[mid / cols][mid % cols]` — O(log(rows·cols)).

### Set matrix zeroes in O(1) extra space
Use the first row and column as markers, with two flags for whether the first row/column themselves must be zeroed.

## 🔴 Senior Level

### Grid graph problems
Treat cells as graph nodes:
* **Number of islands / flood fill** — DFS/BFS marking visited (iterative for large grids: recursion depth up to rows × cols).
* **Shortest path in a binary grid** — BFS from the start; with weights 0/1, 0-1 BFS with a deque; with costs, Dijkstra.
* **Multi-source BFS** — start from *all* sources at once (rotting oranges, distance to nearest gate):

```java
int[][] distanceToNearestZero(int[][] grid) {
    int rows = grid.length, cols = grid[0].length;
    int[][] dist = new int[rows][cols];
    Deque<int[]> q = new ArrayDeque<>();
    for (int r = 0; r < rows; r++)
        for (int c = 0; c < cols; c++) {
            if (grid[r][c] == 0) q.offer(new int[]{r, c});
            else dist[r][c] = Integer.MAX_VALUE;
        }
    while (!q.isEmpty()) {
        int[] cur = q.poll();
        for (int[] d : DIRS) {
            int nr = cur[0] + d[0], nc = cur[1] + d[1];
            if (nr >= 0 && nr < rows && nc >= 0 && nc < cols && dist[nr][nc] > dist[cur[0]][cur[1]] + 1) {
                dist[nr][nc] = dist[cur[0]][cur[1]] + 1;
                q.offer(new int[]{nr, nc});
            }
        }
    }
    return dist;
}
```

### DP on grids and prefix sums
* **Minimum path sum / unique paths** — `dp[r][c]` from top and left; rolling 1D array.
* **Maximal square** — `dp[r][c] = 1 + min(top, left, topLeft)` if cell is 1.
* **2D prefix sums** for O(1) rectangle sum queries after O(rows·cols) preprocessing:

```java
// P has one extra row and column of zeros
int[][] prefix(int[][] m) {
    int R = m.length, C = m[0].length;
    int[][] P = new int[R + 1][C + 1];
    for (int r = 0; r < R; r++)
        for (int c = 0; c < C; c++)
            P[r + 1][c + 1] = m[r][c] + P[r][c + 1] + P[r + 1][c] - P[r][c];
    return P;
}
int sum(int[][] P, int r1, int c1, int r2, int c2) {   // inclusive corners
    return P[r2 + 1][c2 + 1] - P[r1][c2 + 1] - P[r2 + 1][c1] + P[r1][c1];
}
```

### Memory and performance notes
* `int[][]` in Java is an array of separate row arrays (not one contiguous block); for heavy numeric work, a flattened `int[rows * cols]` improves locality and removes a level of indirection.
* Encoding a cell as `r * cols + c` in a single `int` avoids allocating `int[]` pairs in BFS queues (fewer objects, less GC).
* Sparse matrices (mostly zeros) are better stored as maps or CSR (compressed sparse row) structures.

## 🎯 Interview Cheat Sheet

**30-second pitch:** Matrix problems reward clean indexing: direction arrays, bounds checks, and boundary pointers for spirals. Rotation is transpose plus row reversal; sorted-matrix search starts from the top-right; grids are graphs for BFS/DFS including multi-source BFS; DP and 2D prefix sums answer path and rectangle queries efficiently.

**Must know:**
* `DIRS` array and `inBounds` helper.
* In-place rotation; spiral traversal guards.
* Top-right search O(r + c); 1D binary search on fully sorted matrices.
* Multi-source BFS; iterative flood fill for large grids.
* 2D prefix sums formula.

**Common follow-ups:**
* Rotate counter-clockwise?
* Count islands when the grid is huge (streaming rows)?
* Why is column-major traversal slower in Java?

**Red flags:** recursive DFS on a 10⁶-cell grid; off-by-one errors in spirals; allocating new arrays per BFS step needlessly.
