# How to traverse binary trees with DFS and BFS

---

## 🟢 Junior Level

A **binary tree** is a structure where each node has at most two children, `left` and `right`. Most tree problems are solved by visiting every node in a specific order:

* **DFS (depth-first search)** — go as deep as possible before backtracking. Three orders:
  * **Preorder**: node → left → right (copying/serializing a tree)
  * **Inorder**: left → node → right (sorted order in a BST)
  * **Postorder**: left → right → node (deleting a tree, computing heights/sums bottom-up)
* **BFS (breadth-first search)** — visit level by level using a **queue** (shortest path in unweighted trees, level-order output).

```java
public class TreeNode {
    int val;
    TreeNode left, right;
    TreeNode(int val) { this.val = val; }
}

// Recursive DFS — inorder
void inorder(TreeNode node, List<Integer> out) {
    if (node == null) return;
    inorder(node.left, out);
    out.add(node.val);
    inorder(node.right, out);
}

// BFS — level order, one list per level
List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> levels = new ArrayList<>();
    if (root == null) return levels;
    Deque<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int size = queue.size();                 // nodes in the current level
        List<Integer> level = new ArrayList<>(size);
        for (int i = 0; i < size; i++) {
            TreeNode n = queue.poll();
            level.add(n.val);
            if (n.left != null) queue.offer(n.left);
            if (n.right != null) queue.offer(n.right);
        }
        levels.add(level);
    }
    return levels;
}
```

Both are **O(n)** time. DFS uses O(h) stack space (h = height); BFS uses O(w) queue space (w = max width).

## 🟡 Middle Level

### Iterative DFS (avoid stack overflow on deep trees)

```java
List<Integer> inorderIterative(TreeNode root) {
    List<Integer> out = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode cur = root;
    while (cur != null || !stack.isEmpty()) {
        while (cur != null) { stack.push(cur); cur = cur.left; }   // go left as far as possible
        cur = stack.pop();
        out.add(cur.val);
        cur = cur.right;
    }
    return out;
}
```

A degenerate (linked-list-like) tree with 100,000 nodes overflows the default thread stack (~512 KB–1 MB) with recursion; iterative traversal avoids that.

### The "return info from children" template (postorder)
Many problems compute something per subtree and combine:

```java
// Maximum depth
int maxDepth(TreeNode n) {
    if (n == null) return 0;
    return 1 + Math.max(maxDepth(n.left), maxDepth(n.right));
}

// Is the tree height-balanced? Return -1 as a "not balanced" signal to stay O(n)
int heightOrMinusOne(TreeNode n) {
    if (n == null) return 0;
    int l = heightOrMinusOne(n.left);
    if (l < 0) return -1;
    int r = heightOrMinusOne(n.right);
    if (r < 0 || Math.abs(l - r) > 1) return -1;
    return 1 + Math.max(l, r);
}
```

### The "pass info down" template (preorder)

```java
// Root-to-leaf path sum equals target?
boolean hasPathSum(TreeNode n, int remaining) {
    if (n == null) return false;
    remaining -= n.val;
    if (n.left == null && n.right == null) return remaining == 0;
    return hasPathSum(n.left, remaining) || hasPathSum(n.right, remaining);
}
```

## 🔴 Senior Level

### Classic problems and the traversal that solves them

| Problem | Approach |
| --- | --- |
| Diameter of a tree | Postorder: at each node, `leftHeight + rightHeight`; track global max |
| Lowest common ancestor (binary tree) | Postorder: return node if it's p or q; if both sides return non-null, current node is LCA |
| Right side view | BFS: last node of each level (or DFS right-first with depth) |
| Serialize/deserialize | Preorder with null markers |
| Validate BST | Inorder strictly increasing, or DFS with (min, max) bounds using `long`/nullable bounds |
| Zigzag level order | BFS with alternating insertion into a `Deque` |
| Maximum path sum (any node to any node) | Postorder returning best downward path; global max includes both sides |

```java
// Lowest common ancestor in O(n)
TreeNode lca(TreeNode node, TreeNode p, TreeNode q) {
    if (node == null || node == p || node == q) return node;
    TreeNode left = lca(node.left, p, q);
    TreeNode right = lca(node.right, p, q);
    if (left != null && right != null) return node;   // p and q found in different subtrees
    return left != null ? left : right;
}

// Maximum path sum
private int best = Integer.MIN_VALUE;
int maxPathSum(TreeNode root) { gain(root); return best; }
private int gain(TreeNode n) {
    if (n == null) return 0;
    int l = Math.max(0, gain(n.left));                 // ignore negative branches
    int r = Math.max(0, gain(n.right));
    best = Math.max(best, n.val + l + r);              // path through n
    return n.val + Math.max(l, r);                     // best path continuing upward
}
```

### Morris traversal (O(1) extra space)
Inorder without stack or recursion by temporarily threading right pointers of predecessors back to the current node — rarely needed in practice, but a good signal of depth if asked for O(1) space. It modifies the tree temporarily, so it's not safe with concurrent readers.

### Interview tips
* State the traversal choice and why (need levels → BFS; need subtree results → postorder).
* Mention complexity including space: O(h) recursion, O(n) worst case for skewed trees.
* Use `ArrayDeque` (not `Stack`/`LinkedList`) in Java: faster, no synchronization; note `ArrayDeque` rejects `null` elements.

## 🎯 Interview Cheat Sheet

**30-second pitch:** DFS goes deep — preorder, inorder, postorder — recursively or with a stack in O(h) space; BFS goes level by level with a queue in O(w) space; both are O(n) time. Most tree problems are "pass info down" (preorder) or "combine results from children" (postorder), and level-based questions use BFS with the queue size per level.

**Must know:**
* Preorder/inorder/postorder use cases; inorder of a BST is sorted.
* Level-order BFS with `queue.size()` per level.
* Iterative DFS to avoid stack overflow.
* Templates: diameter, LCA, max path sum, validate BST with bounds.
* `ArrayDeque` for stacks and queues.

**Common follow-ups:**
* What's the space complexity on a skewed tree?
* How do you validate a BST without overflow issues?
* How would you serialize a tree?

**Red flags:** validating a BST by comparing only parent and child; recursive solutions without considering depth; using `java.util.Stack`.
