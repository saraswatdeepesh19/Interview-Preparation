<section class="section">
  <h2>What this architecture section includes</h2>
  <p>The section starts at the code level with clean code principles, refactoring, and code smells, then moves up to application structure: layered, hexagonal, clean, and onion architectures, and Domain-Driven Design.</p>
  <p>At the system level it compares modular monoliths, microservices, and serverless, explains the strangler fig approach to decomposing a monolith and where Spring Modulith fits, and shows how to record decisions with ADRs and the C4 model.</p>
</section>
